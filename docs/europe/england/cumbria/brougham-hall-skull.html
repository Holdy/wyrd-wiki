    Brougham Hall skull

    Summary

    A skull at Brougham Hall caused trouble whenever it was taken away. To put an end to it, someone walled it up inside a room of the hall.

    Details

    Brougham Hall had a skull that would not tolerate being moved: each time it was removed, trouble followed. In the end it was walled up inside one of the hall's rooms so it could never be taken away again.
