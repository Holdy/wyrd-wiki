Phantom Cars at Dead Man's Curve

Summary

Dead Man's Curve is haunted by a phantom Roadrunner and Impala that try to run drivers off the road following a fatal 1969 crash.

Details

In October of 1969, five teenagers were killed at Dead Man's Curve when their Impala was run off the road by a Roadrunner. Ever since the accident, the road has been haunted by a phantom Roadrunner and Impala that reportedly try to run drivers off the road.
