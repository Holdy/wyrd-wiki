#title
Bigfoot Sightings in Ohio State Parks
#summary
The famous ape-like cryptid Bigfoot has been spotted across multiple Ohio state parks, including Hocking Hills State Park.
#details
Bigfoot has been seen at several locations across Ohio, including Mohican State Park in Loudonville, West Branch State Park in Ravenna, and Hocking Hills State Park in Logan. The creature's presence in Hocking Hills is celebrated with an annual festival.
